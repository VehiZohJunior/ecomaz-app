Séance avec l’équipe de l’école

Prise en main en 1 heure

À faire ensemble, sur place, avec la Direction, la secrétaire et les enseignants. Cochez chaque étape terminée.

1Installer et activer les notifications10 min

  • Sur le téléphone de chacun : ouvrir le lien dans Chrome, se connecter, Installer l’application.
  • Tableau de bord → Activer les notifications → Autoriser.

2Saisir les enseignants10 min

  • Enseignants → + Nouvel enseignant : nom, numéro WhatsApp, classes.
  • Imprimer les badges QR (Scanner un badge).

3Faire un premier appel5 min

  • Pointage élèves (Appel) → Tous présents → toucher les absents → Enregistrer.
  • Chaque enseignant le fait dans sa classe, chaque matin avant 9h00.

4Vérifier les fiches élèves5 min

  • Élèves & Inscriptions → encadré Fiches à vérifier → Corriger (dates, numéros des parents).

5Paramétrer la scolarité10 min

  • Paramètres → Scolarité et tranches : créer la grille d’une classe par niveau, puis la copier.
  • Enregistrer les paiements déjà reçus (Comptabilité → Scolarité).

6Inviter les parents5 min

  • Parents ↔ Élèves → imprimer les coupons d’invitation → les glisser dans les cahiers.
  • La Direction valide chaque demande (Paramètres → Demandes d’accès).

7Renforcement et horaires5 min

  • Cours de renforcement : cocher les élèves concernés.
  • Vérifier les horaires et les jours de classe (Paramètres → Annonces horaires).

8Première publication5 min

  • Vie de l’école : publier quelques photos d’une activité récente (avec l’accord des parents).
  • Ajouter le logo de l’école (Paramètres).

Ensuite, chaque jour

Matin : appel avant 9h00. Dans la journée : encaisser et imprimer les reçus, répondre aux parents. Vendredi : Tableau de bord → Bilan de la semaine. La liste Mise en route de l’école du tableau de bord montre ce qui reste à faire.
